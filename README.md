# 🏎️ ربات مسابقهٔ ماشین تلگرام

بازی مسابقهٔ ماشین با **تعویض دنده** برای گروه‌ها و سوپرگروه‌های تلگرام. تمام متن‌های ربات فارسی است.

## راه‌اندازی

1. پایتون ۳٫۱۰ یا بالاتر
2. `pip install -r requirements.txt`
3. در [@BotFather](https://t.me/BotFather) ربات بسازید و توکن را بگیرید
4. فایل `.env.example` را به `.env` تغییر نام بدهید و توکن را داخلش بگذارید
5. `python bot.py`
6. ربات را به یک گروه اضافه کنید و بنویسید `/race`
   (چت خصوصی ربات: `/start` ← راهنمای بازی، ماشین من، موجودی من)

## فایل‌ها

| فایل | کار |
|---|---|
| `config.py` | **تمام عددهای بالانس**: مسافت، سرعت، دنده‌ها، RPM، جایزه‌ها، هزینه و اثر آپگریدها |
| `engine.py` | موتور بازی (مستقل از تلگرام): شبیه‌سازی RPM/سرعت، تعویض دنده، رتبه‌بندی، پایان مسابقه |
| `database.py` | دیتابیس SQLite: بازیکن‌ها، آپگریدها، آمار، وضعیت مسابقه‌ها |
| `bot.py` | هندلرهای تلگرام + رندر پیام‌ها (UI) + اجرای مسابقه |
| `colors.py` | رنگی کردن همهٔ دکمه‌های شیشه‌ای (سبز / قرمز / آبی) |

## چطور کار می‌کند

- **یک پیام اصلی** برای کل مسابقه؛ هر ۱٫۵ ثانیه ویرایش می‌شود و گروه پر از پیام نمی‌شود.
- تلگرام اجازه نمی‌دهد یک پیام برای هر نفر دکمهٔ جدا نشان دهد؛ پس **زیر پیام برای هر بازیکن یک دکمهٔ مخصوص خودش** هست
  (`🟢 Ali ⚡ دنده 4`). دکمهٔ هر نفر فقط برای خودش کار می‌کند؛ بقیه پیام «❌ این کنترل برای شما نیست» می‌گیرند.
  هر کلیک با User ID و Race ID چک می‌شود.
- RPM هر ماشین با زمان واقعی بالا می‌رود (سمت سرور). نتیجهٔ کلیک بر اساس RPM لحظهٔ کلیک حساب می‌شود، نه بر اساس پیام قدیمی.
- قبل از محدودهٔ سبز: هیچ اتفاقی نمی‌افتد (فقط پیام «هنوز زوده»).
  داخل سبز: 🔥 تعویض عالی (افزایش سرعت + Boost کوتاه).
  بعد از سبز و قبل از ۲ ثانیه: تعویض دیرهنگام (بدون پاداش).
  ۲ ثانیه بعد از سبز: ⚠️ تعویض از دست رفته ← ماشین خودش دنده را عوض می‌کند و ۳٪ سرعت کم می‌شود.
- وقتی فقط یک نفر بدون رتبه بماند، رتبهٔ آخر را می‌گیرد و مسابقه همان لحظه تمام می‌شود.
- بعد از مسابقه Coin پرداخت و آمار ذخیره می‌شود. ارتقا: چت خصوصی ← «🏎️ ماشین من».
- وضعیت مسابقه (پیشروی، دنده، سرعت، RPM، تعویض‌ها، رتبه) هر تیک در دیتابیس ذخیره می‌شود.
  اگر ربات وسط مسابقه ری‌استارت شود، مسابقهٔ نیمه‌کاره `aborted` ثبت می‌شود (Coin پرداخت نمی‌شود).

## بالانس فعلی (نتیجهٔ شبیه‌سازی)

- مسابقهٔ ۱۰۰۰ متری: حدود **۴۳ ثانیه** با ماشین سطح ۱، حدود **۳۲ ثانیه** با ماشین کاملاً ارتقا‌یافته.
- مهارت مهم است: بدون هیچ تعویضی حدود ۵ ثانیه کندتر از تعویض کامل هستید؛ این فاصله تقریباً معادل همهٔ آپگریدها تا سطح ۲۰ است.
- ضریب موتور طبق سند (۱٫۰۴ / ۱٫۰۸ / ۱٫۱۷ / ≈۱٫۴۱ در سطح ۱۰ / ≈۱٫۹۸ در سطح ۲۰) محاسبه می‌شود، ولی برای اینکه بازی غیرقابل رقابت نشود
  فقط ۱۵٪ از آن روی سرعت مسابقه اثر می‌گذارد (`ENGINE_RACE_WEIGHT`).
- هزینهٔ ارتقای موتور: ۱۰۰، ۱۵۰، ۲۲۵، ۳۴۰، ... مثل سند تا سطح ۱۰ (۲٬۶۰۰)، بعد رشد کندتر می‌شود.
  رساندن همهٔ ۶ بخش به سطح ۵۰ در حدود ۳۰٬۰۰۰ مسابقه طول می‌کشد.

## تغییر بالانس

همه‌چیز در `config.py`:

- `RACE_DISTANCE`، `DISTANCE_SCALE` (زمان کل مسابقه)، `GEAR_COUNT` و جدول‌های هر دنده
- `GREEN_SECONDS`، `MISS_TIMEOUT`، `MISS_PENALTY`، `PERFECT_BOOST`
- `REWARDS` (جایزه‌ها برای هر تعداد بازیکن) و `UPGRADES` / فرمول هزینه‌ها
- `TICK_SECONDS`: اگر تلگرام خطای «Too Many Requests» داد، این عدد را بیشتر کنید (مثلاً ۲).

اگر `GEAR_COUNT` را عوض کردید، لیست‌های `GEAR_TOP_SPEED`، `GEAR_RPM_RATE` و `GREEN_START_RPM` باید همان تعداد عضو داشته باشند
(هنگام اجرا چک می‌شود).

## دکمه‌های رنگی

همهٔ دکمه‌های شیشه‌ای با `colors.py` رنگ می‌گیرند (نیاز به python-telegram-bot نسخهٔ ۲۲٫۶ به بالا و اپ تلگرام به‌روز):
🟢 سبز = پیوستن، شروع، تأیید، دکمهٔ «الان تعویض کن»؛ 🔴 قرمز = خروج، لغو، «دیر شد»؛ 🔵 آبی = بقیه.
برای تغییر رنگ‌ها جدول‌های بالای `colors.py` را ویرایش کنید؛ برای خاموش کردن موقت: `BUTTON_COLORS=0` در `.env`.
